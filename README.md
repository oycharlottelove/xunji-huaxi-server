# 循迹·化析 —— 高中化学「工业流程 / 有机推断」步进式思维脚手架智能体

华中师范大学首届（2026年）大学生 AIGC 教学应用竞赛 · 应用赛道参赛原型。

## 核心设计理念
针对搜题软件“直接给答案、学生一听就会一做就废”的痛点，本应用基于 **DeepSeek-Flash（多模态识图 + 化学推理，单一模型打通）**，将复杂的化工工业流程或有机合成推断题拆解为可交互的**步进式思维脚手架节点**：
1. **第 1 层（审题破冰）**：提出苏格拉底式启发反问，学生先写思路并由 AI 即时点评；
2. **第 2 层（方法点拨）**：按需解锁“思考方向”与“关键试剂/原理”提示，绝不提前剧透答案；
3. **第 3 层（规范解析）**：核对配平方程式与高考高频失分陷阱；
4. **靶向巩固与复盘**：记录学生求助层级，自动计算独立思考率并针对薄弱节点生成变式微练习。

## 快速启动
无需安装任何第三方 npm 依赖（基于 Node.js 原生模块与 `fetch`）：

1. 复制 `.env.example` 为 `.env` 并填入你的 `DEEPSEEK_API_KEY`（也可以不填，直接在网页右上角弹窗临时配置，或使用内置高考真题离线演示模式）。
2. 在项目目录启动服务：
   ```bash
   node server.js
   ```
3. 浏览器访问 `http://localhost:3000`。

## 模型说明（2026-11）

- 全线统一使用 `deepseek-flash`（支持图像理解，识图与化学推理共用同一个模型，不再区分 `deepseek-chat`）。
- 题目拆解接口默认**开启思考模式**（推理更稳，实测约 20–40 秒）；学生思路点评与变式题接口**已关闭思考模式**（实测 1–2 秒，且 `temperature` 才真正生效）。
- 若要演示时更快：启动前设置环境变量 `ANALYZE_EFFORT=low`（可选 `low` / `high` / `max`）。
